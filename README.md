# Chapter Player

**iPhone・Android用。まずZIPを展開して「00_アプリはこちら.pdf」を開いてください。**

## まずZIPをダウンロードしましょう

[📥 PDF説明書付きのZIPをダウンロード](https://github.com/fuyumoe2016/chapter-player/releases/download/v1.1.0/Chapter_Player_v1.1.0.zip)

1. ZIPをダウンロードして展開します。iPhoneは「ファイル」でZIPをタップ、Androidはファイル管理アプリで解凍してください。
2. **「00_アプリはこちら.pdf」を開きます。**
3. PDFの1ページ目の大きな「タップしてアプリを開く」を押し、開いたページをブックマークしてください。

同じスマホでPDFを見ている場合はリンクをタップしてください。別の端末や印刷したPDFを見ている場合は、QRコードからもアプリをひらけます。操作説明はこのPDF1冊にまとめています。

## アドレスバーなしで使う方法

- **iPhone：** Safariで開き、「共有」→「ホーム画面に追加」→「追加」。「Webアプリとして開く」が表示されたらオンにしてください。
- **Android：** Chromeのメニュー→「ホーム画面に追加」または「インストールしてショートカットを作成」→「インストール」。

追加したホーム画面のアイコンから開いてください。通常のブラウザタブやブックマークから開く場合はアドレスバーが表示されます。メニュー名はOS・ブラウザで異なります。

## HTMLを開いた場合

HTMLを開くと２つの選択肢が出てきます。

「Chapter_Player.html」の「アプリで使う」でPDF、「デスクトップで使う」で公開アプリが開きます。スマホのファイル閲覧画面でリンクを開けない場合はPDFを直接開いてください。

## 保存と更新

ログイン・登録は不要です。記録は端末のブラウザ内に自動保存し、クラウド同期はありません。設定からJSONバックアップを書き出し・読み込みできます。閲覧データの削除や機種変更前にはバックアップしてください。

アプリ本体は再読み込みで更新でき、ZIPの再ダウンロードは不要です。説明書も更新した場合は同じ固定URLから最新ZIPを取得してください。

Archive_から始まる添付ZIPは過去のダウンロード記録を残す控えです。初めての方は上のリンクからChapter_Player_v1.1.0.zipを選んでください。
