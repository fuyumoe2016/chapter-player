# Chapter Player

iPhone Safari向けYouTubeチャプター動画プレイヤー。v1.1.0から **ログイン・登録・メール申請不要** の配布版を用意しました。

利用URL: https://chapter-player-open.fuyumoe.chatgpt.site

配布ZIPは **Releases** の `Chapter_Player_v1.1.0.zip` を選んでください。公開URLを開くHTML、PDF説明書1冊、静的配信用のdist、開発者向けソースを同梱しています。操作説明はPDFへ集約しています。

記録は各端末のブラウザ内に自動保存されます。クラウド同期はありません。設定からJSONバックアップを書き出し、新しい端末で読み込んで復元できます。閲覧データの削除や端末変更の前にはバックアップを保管してください。

YouTube再生にはインターネット接続とHTTPSの公開URLが必要です。ZIP内のHTMLは公開版を開くための入口です。distはGitHub Pagesなどの静的HTTPSホストへ配信できます。

本人専用の旧クラウド版は維持しています。旧版の保存データは認証なし版へ自動移行されません。
