# Chapter Player

iPhone Safari向けのYouTubeチャプター動画プレイヤーです。

配布ZIPは、このリポジトリの **Releases** からダウンロードしてください。
ZIPにはアプリの利用URLを開くHTML、PDF説明書1冊、開発者向けソースを同梱しています。使い方はPDFへ集約しています。

Web版: https://fuyumoe-chapter-player.fuyumoe.chatgpt.site

現在のWeb版を使うには、所有者によるアクセス許可が必要です。ZIPをダウンロードしてもアクセス許可は付与されません。
クラウド認証・保存を含むため、ソースをファイルとして開くだけではアプリは動きません。別環境での稼働には認証・保存先の設定が必要です。

Web版の更新は同じURLに反映されます。作業を保存してから再読み込みしてください。
